### About me

I build things to understand how they work. My projects cover drone vision, GPS-denied drone swarms, agentic AI systems and measurement hardware, and I take part in robotics and Inter-IIT style competitions.

I'm currently working on:

- Thermal UAV image to satellite geo-localisation for an Inter-IIT problem, running on an edge device
- An onboard-only drone swarm for Robofest
- An auto-balancing bridge impedance meter (R, L, C) with multi-method calibration
- A browser-based AI task worker that verifies its own actions

### Projects

**[yolov8-visdrone](https://github.com/prabhuparth442/yolov8-visdrone)**
Object detection on drone imagery with YOLOv8, trained on VisDrone.

**[IdeaForge-GeoLoc-InterIIT15](https://github.com/prabhuparth442/IdeaForge-GeoLoc-InterIIT15)**
Geo-localisation of thermal UAV images against satellite imagery for Inter-IIT.

**[Gujcost-Robofest-Resource-IITBBS](https://github.com/prabhuparth442/Gujcost-Robofest-Resource-IITBBS)**
Resources and code for a GPS-denied drone swarm built for Robofest.

**[Center_Align_Agentic_Project](https://github.com/prabhuparth442/Center_Align_Agentic_Project)**
An autonomous AI worker that operates mail and finance apps and reads back to verify what it did.

**[MEI_Impedance_Meter](https://github.com/prabhuparth442/MEI_Impedance_Meter)**
An auto-balancing bridge impedance meter with calibration.
